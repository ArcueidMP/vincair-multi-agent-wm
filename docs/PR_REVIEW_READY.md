## 可直接使用的说明正文

### 变更

- 集成队友E4 notebook基线，增加无渲染原生VMAS复现、子步安全标签、分组数据与独立数值核验。
- 增加直接状态/动作评分器、泛化与失败诊断、目标代价对照、闭环确认及新压力测试，保留失败门槛。
- 提供便携JSON评分器、共享复现/对照工具、历史E0/E1选定报告及最终E1源码、数据资产索引。
- 增加个人阶段工作说明与团队协作任务清单；原始大数组及作者模型不提交到Git。

### 关键证据

- 解析目标代价+冻结风险过滤：此前新确认12/12和四条件鲁棒性24/24安全到达。
- 更难的新压力测试：近距离条件6/6安全到达；高惯性条件到达6/6但安全到达0/6，真实仿真参考6/6安全到达。该失败限制所有广泛安全论断。
- 线性代价修正器没有通过预设闭环门槛，保留负结果。
- 本机干净clone72集逐集指标一致、720项数组字段逐元素一致；不是队友跨机器独立复现。

### 验证

- 针对性测试、每次原生状态/子步行动回放、独立NumPy预测/候选选择/物理标签核验；精确测试数与误差见最新报告。
- 小模型参数与归一化统计导出前后精确一致；原始轨迹与模型/协议hash可追溯。
- 文档相对链接与历史迁移文件hash检查。全量历史训练/作者模型没有在本轮重跑。

### 已知限制和评审重点

1. 目前是双机直接评分器与解析/学习混合基线，不是Navigation LeWM；模型材料仍待提供。
2. 安全按0.30间距、初态+原生子步统计；成功是0.12联合位置容差，不含终态速度。不要把到达率当安全到达率。
3. 相关条件变体不能当独立几何；已使用确认/压力集不再用于调参。
4. 当前JSON只包含我们训练的小评分器；作者权重、原始大数据与私聊截图未上传。
5. 旧E0/E1源仍有绝对路径/外部依赖，迁移不等于完整跨机器可运行。
